# Quality check: 10 engineering rules (2026-11-01)

Scope: `src/main/java/portfolio/sketches` (Murmur3, HyperLogLog, Count-Min, heavy hitters, CLI) and
`src/test`. Windows 11, OpenJDK 21.0.12, Maven with `-Xmx1g`.

| # | Rule | Status | Evidence |
|---|---|---|---|
| 1 | Every call can fail | pass | No network or service calls. File I/O in the CLI maps `NoSuchFileException`, `FileAlreadyExistsException` and other `IOException`s to exit codes with a message (`cli/Main.java:67-79`); no empty `catch`. `NumberFormatException` in `Args` becomes a usage error. |
| 2 | Writes safe to retry | pass | The only write is `generate`, which opens with `CREATE_NEW` (`LogGenerator.java:47`): a rerun refuses to overwrite instead of appending twice (EndToEndTest "no overwrite"). |
| 3 | No race conditions | pass (documented) | Sketches are single-writer by design; each class Javadoc says "Instances are not thread-safe" and RFC 0001 says to use one sketch per thread. No static mutable state. |
| 4 | Don't trust the clock | pass | Timings use `System.nanoTime()` (`AccuracyBench.java:45`, `Main.java:98`); no wall-clock deltas, no stored timestamps. |
| 5 | Read before changing | pass | No environment variables read; every path in the README exists. |
| 6 | Never break compatibility | pass | No public API or output format changed in this pass (tests only). |
| 7 | One source of truth | pass | Versions live in `pom.xml`; the Makefile and README test counts were updated to 56. |
| 8 | Small changes, no secrets, validate input | pass | No secrets. Every constructor validates its arguments (precision 4..18, depth/width limits, epsilon/delta in (0,1), `k` and `phi` ranges); the line reader caps line length and the client field is checked. |
| 9 | Tests that can fail | fixed | No `@Disabled` or tautologies. 10 hand mutants: 6 killed before; 3 new tests kill 3 more; 1 is equivalent. |
| 10 | Re-verify | pass | Results below. |
